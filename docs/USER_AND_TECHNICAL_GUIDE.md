# Руководство пользователя и разработчика

## 1. Назначение и текущая готовность

Приложение хранит несколько колод, позволяет редактировать пары «задание — ответ» и генерирует A4 PDF размером 2 × 4 карточки. PDF строится не браузером: сервер экранирует текст, формирует LaTeX и запускает `pdflatex` во временном каталоге.

Текущая версия подходит для редактирования контента и технического просмотра LaTeX. Для ответственной двусторонней печати сначала должны быть устранены блокеры `BUG-PRINT-001…003` из [плана](REMEDIATION_PLAN.md). Особенно важно: при двух и более физических листах страницы сейчас идут как `front-1, front-2, …, back-1, back-2`, поэтому обычная duplex-печать совмещает разные листы.

## 2. Установка

### Системные требования

- Python 3.11 или новее (аудит выполнен на Python 3.13.5);
- Flask 3.1;
- `pdflatex` и LaTeX-пакеты `extarticle`, `amsmath`, `mathtext`, `babel` с русским языком, `geometry`, `graphicx`, `enumitem`, `multicol`, `xcolor`;
- современный браузер; Chromium нужен только для регенерации скриншотов.

Установка и запуск:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd app
../.venv/bin/python run.py
```

Проверка TeX:

```bash
pdflatex --version
kpsewhich mathtext.sty
kpsewhich babel-russian.tex
```

## 3. Работа с приложением

### Колоды

Стартовая страница создаёт, открывает, переименовывает, клонирует и удаляет колоды. Удаление необратимо: корзины и резервной копии пока нет.

![Список колод](images/decks.png)

На снимке также виден подтверждённый дефект `BUG-UI-002`: текст `HTML` после таблицы попал из хвоста шаблона и не является элементом интерфейса.

### Добавление карточек

В редакторе доступны четыре пути:

1. Одна карточка — заполнить хотя бы одну сторону и нажать «Добавить карточку».
2. Пакетный ввод — одна карточка на строку.
3. CSV — первые две колонки интерпретируются как лицевая и оборотная стороны.
4. Редактирование уже добавленной карточки.

![Редактор и таблица карточек](images/deck-editor.png)

Важное расхождение текущей реализации с подписями UI:

- фактически работающий пакетный разделитель — один символ `|`; документированный `||` оставляет лишний `|` в ответе (`BUG-IMP-001`);
- фактически работающий CSV-разделитель — запятая; подпись обещает точку с запятой (`BUG-IMP-002`);
- CSV должен быть в UTF-8 или UTF-8 с BOM; заголовок автоматически не распознаётся и будет импортирован как карточка.

До исправления используйте, например:

```text
Столица Франции | Париж
$2^5$ | $32$
```

или:

```csv
Столица Франции,Париж
$2^5$,$32$
```

### Формулы и превью

LaTeX-формулы задаются как `$...$` или `$$...$$`. Обычные символы `%`, `&`, `_`, `{`, `}` и другие сервер экранирует, а содержимое математических delimiters оставляет без фильтрации.

![Редактирование и формула MathJax](images/edit-card.png)

MathJax в браузере загружается с jsDelivr. Без интернета общее превью отображает исходные `$...$`, что видно на следующем снимке; PDF при установленном TeX всё равно формирует формулы корректно.

![Сетка превью без доступного CDN](images/card-preview.png)

Не вводите непроверенные TeX-команды: текущая allowlist отсутствует, и команды внутри `$...$` могут попасть непосредственно в компилятор (`BUG-SEC-001`).

### Генерация PDF

- «Предпросмотр LaTeX» показывает исходник.
- «Сгенерировать PDF» запускает `pdflatex` с таймаутом 30 секунд.
- Неполный лист дополняется пустыми ячейками до восьми карточек.
- При кириллическом названии колоды реальный Werkzeug dev-сервер не может закодировать имя файла в HTTP-заголовке (`BUG-HTTP-003`). Временный обход — ASCII-название колоды перед скачиванием.

Лицевая страница реального PDF из аудита:

![Лицевая страница PDF](images/print-page-1.png)

Оборотная страница той же колоды:

![Оборотная страница PDF](images/print-page-2.png)

На обороте рамка по умолчанию невидима. Текст всегда повёрнут на 180°, а колонки зеркальны. Эта комбинация не является корректной универсальной раскладкой ни для всех принтеров, ни для обоих вариантов переворота листа. Печатать «в размер» нужно только с масштабом 100% / Actual size, без `Fit`, но это само по себе не устраняет логические ошибки раскладки.

## 4. Хранение данных

При рекомендованном запуске из `app/`:

```text
app/data/decks.json           # метаданные и card_ids
app/data/cards/<deck-id>.json # содержимое карточек колоды
```

Путь сейчас относительный. Если запустить `python app/run.py` из корня, будет создан другой каталог `./data`, что выглядит как исчезновение колод (`BUG-CONF-001`). JSON пишется напрямую, без блокировки, атомарной замены, схемы и резервного копирования. Перед экспериментами вручную копируйте `app/data`.

## 5. Архитектура

```text
Browser / HTML / JSON API
          |
      Flask blueprint
          |
  card/deck use cases
          |
  +-------+----------------+
  |                        |
JsonRepository       LatexRenderer
  |                        |
JSON files             PdfLatexCompiler
                           |
                        A4 PDF
```

- `domain/entities.py`: карточка, метаданные колоды, рабочая `CardDeck`.
- `use_cases/`: CRUD, импорт, padding, preview и generate.
- `adapters/json_repository.py`: активное файловое хранилище.
- `adapters/latex_renderer.py`: физическая сетка и зеркалирование.
- `web/blueprint.py`: HTML и AJAX endpoints.
- `xelatex_compiler.py`: протестированная альтернативная реализация компилятора; активная конфигурация пока использует `pdflatex`.

`CardLayoutConfig` задаёт `9.3 × 6.3 см`, 2 столбца, 4 ряда и `fboxsep=8pt`. Эти размеры относятся к внутренней `minipage`; физическая рамка получается примерно `9.89 × 6.89 см` с учётом padding и border (`BUG-PRINT-003`).

## 6. Тесты и воспроизводимость аудита

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m pytest --cov=didactic_cards --cov=run --cov=config --cov-branch
```

`xfail(strict=True)` — не пропущенные тесты, а исполнимые спецификации известных дефектов. После исправления соответствующий тест неожиданно пройдёт (`XPASS`) и заставит удалить метку, сохранив сценарий как обычную регрессию.

Скриншоты можно переснять на запущенном приложении:

```bash
python scripts/capture_screenshots.py \
  --base-url http://127.0.0.1:5000 \
  --deck-id <UUID-колоды> \
  --output-dir docs/images
```

Скрипт использует системный Chromium и не скачивает собственный браузер.

## 7. Диагностика

- `Exec format error` у `venv/bin/python`: удалите/не используйте непереносимое окружение и создайте `.venv` заново.
- `pdflatex not found`: установите TeX Live и проверьте `pdflatex --version`.
- Страница ошибки LaTeX: откройте полный лог, найдите первую строку, начинающуюся с `!`.
- Формулы видны как `$x^2$` только в браузере: недоступен MathJax CDN; это не обязательно означает сбой PDF.
- Колоды «пропали»: проверьте текущий каталог процесса и наличие двух разных `data/`.
- PDF компилируется, но не скачивается: используйте ASCII-название до исправления `BUG-HTTP-003`.
