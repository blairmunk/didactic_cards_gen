# Протокол физической приёмки двусторонней печати

Статус: **ожидает измерений на реальном принтере**. Программная геометрия, PDF и
калькулятор компенсации проверены автоматически, но драйвер, тракт подачи и перекос
бумаги можно оценить только по отпечатку.

## Паспорт прогона

Заполните один протокол для каждой комбинации принтера, драйвера и бумаги.

| Поле | Значение |
|---|---|

| Масштаб в диалоге печати | `100% / Actual size`, Fit/Shrink выключены |
| Версия приложения / commit | |

## Критерии

Рекомендуемые критерии проекта можно ужесточить под конкретный резак:

- контрольный отрезок: **99,5–100,5 мм**;
- остаточное расхождение центральной мишени: не более **0,5 мм** по X и Y;
- расхождение каждой угловой мишени: не более **1,0 мм** по X и Y;
- все пары «лицо ↔ оборот» совпадают, текст ориентирован правильно;
- для ручной подачи воспроизводимо записаны сторона листа, верх и порядок страниц.

Смещение всех пяти мишеней примерно на одну величину исправляется offsets. Разный
сдвиг углов означает scale/skew тракта подачи; его нельзя честно исправить одним X/Y.

## Подготовка

1. В тестовой колоде откройте «Сверка сторон», выберите профиль и убедитесь, что при
   нулевых offsets синие/красные cut bounds совпадают после включения отражения.
2. Откройте «Профили принтеров и калибровка».
3. Выберите тот же профиль и скачайте двухстраничный калибровочный PDF.
4. В драйвере выберите A4, портретную ориентацию, `Actual size`, правильный flip mode.
5. Карандашом отметьте на тестовом листе верх и сторону, обращённую к вам в лотке.
6. После печати держите лист лицевой стороной к себе на просвет. Пунктирная мишень
   правее/ниже сплошной даёт положительные X/Y, левее/выше — отрицательные.
7. Введите центральные X/Y в калькулятор приложения, перенесите предложенные
   «Оборот X/Y» в новый профиль и обязательно повторите печать.

## C. Ручная двусторонняя подача

Используйте одну тестовую колоду минимум из девяти пронумерованных карточек, чтобы
проверить два физических листа. Скачайте `*-fronts.pdf` и `*-backs.pdf` с одним
профилем.

1. Напечатайте обе страницы fronts-файла.
2. Запишите, как листы вышли: лицом вверх/вниз, верхним/нижним краем вперёд.
3. Верните листы в лоток и напечатайте backs-файл. Если драйвер меняет порядок,
   применяйте reverse order только в диалоге второго прохода, не меняя PDF.

| Способ возврата листа в лоток | |

| Лист 1: все пары и ориентация | PASS / FAIL |
| Лист 2: все пары и ориентация | PASS / FAIL |
| Рамки/мишени в пределах допуска | PASS / FAIL |
